## Rodando testes

```
./rodar_testes.sh
```

Resultado esperado: `Total: 38 passaram, 0 falharam`.

(Se adicionar mais testes, o resultado esperado vai mudar)

Para adicionar um teste, escreva em `testes.txt`. A estrutura dos testes é mostrada abaixo:

```
### ok | descrição
{ a = 1; }

### erro | descrição
{ a = 1 }
```
